# Django Blog System 

A fully functional blog system built with Django, inspired by the "Django by Example" book. It supports publishing, tagging, commenting, and comes with features like sitemaps and RSS feeds for SEO and content syndication.

---

##  Features

- 📰 Publish, edit, and delete blog posts
- 🧵 Tagging support (using `taggit`)
- 💬 Comment system with moderation
- 🔎 Search functionality
- 📡 RSS & Atom feeds for posts
- 🗺️ XML sitemap for SEO
- 🐳 Docker support 
- ⚙️ Admin panel for content management
